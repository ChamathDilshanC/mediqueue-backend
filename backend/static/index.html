GETTING STARTED

From setup to your first request

A few simple steps to get your integration moving.

01

Create your account

Register a user, confirm their email, then sign in to receive an access token.

02

Register your hospital

Call POST /v1/hospitals with your access token. We create the hospital, its first branch, and your admin membership together.

↳ Save the returned hospital and branch IDs for your scoped requests.
03

Make it flow

Add departments, doctors, and schedules. Create a queue, check in a patient, and call the next token. Every command stays within your selected branch.

ACCESS & PERMISSIONS

A secure foundation

Use a Supabase access token. Permissions come from active database memberships, so a user cannot grant themselves a staff role.

REQUEST HEADERSAuthenticated request
Authorization: Bearer <access_token>
X-Tenant-ID: <hospital_id>
X-Branch-ID: <branch_id>

A single active membership is selected automatically. For multiple branches, send the scope headers explicitly. Check-in and call-next also require an Idempotency-Key.
